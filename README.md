# ひと息メッセージ

## 公開URL
- https://healing-app-wcew.onrender.com

## サービス概要
- 日々の仕事や勉強を頑張っている人が、ひと息ついて、もうひと頑張りできるようなメッセージを表示するサービスです。

## このアイデアはどこから生まれたか
- このアイデアは、私自身が異業界・異業種への転職を経験したことから生まれました。

新しい環境では、これまで経験してきた仕事とは異なることも多く、「誰に何を聞いたらいいのか分からない」「こんなことを聞いてもいいのだろうか」と迷う場面がありました。また、以前よりも人と直接関わる機会が減ったことで、ちょっとした疑問や不安を一人で抱えてしまうこともありました。

こうした経験から、新しい環境で頑張っている人が、少し疲れたときに気軽に気持ちを切り替えられるものがあればいいのではないかと考えました。

そこで、使う人が難しい操作をすることなく、ボタンを押すだけで短いメッセージを受け取り、ひと息つけるようなアプリ「ひと息メッセージ」を考えました。

## 課題の整理（表面的になっていないか）

異業界・異業種への転職後、リモートで研修を受ける中で、分からないことがあったときに「誰に聞けばいいのか」「どの連絡方法を使えばいいのか」「どのくらい待てばいいのか」を判断することに難しさを感じました。

週に一度営業所に行く機会はあっても、そこで会える人が研修に関する疑問や、メール・ポータルサイトに届くメッセージについて答えられるとは限りません。また、面談で研修の方向性を確認することはできても、画面越しのやり取りでは相手の雰囲気や熱量をつかみにくく、自分が何を目標に頑張ればいいのか分からなくなることもありました。

もちろん、仕事上の具体的な疑問を解決するためには、最終的にはしかるべき人に質問する必要があります。そこで、このアプリでは「疑問そのものを解決すること」ではなく、その過程で生まれる「どうしたらいいんだろう」という小さな不安や戸惑いに着目しました。

新しい環境では、一つひとつは小さな困りごとでも、それを誰かに相談することをためらったり、どう行動すればいいのか迷ったりすることで、気づかないうちにストレスが積み重なることがあります。

そこで私は、新しい環境で頑張っている人が、気持ちを少し軽くして「まず聞いてみよう」「もう一度やってみよう」と次の行動に移るためのきっかけを作ることを、このアプリで扱う課題としました。

## 想定ユーザーについて

- 新卒または転職したばかりで、新しい環境での仕事や人間関係に戸惑いを感じている社会人を想定しています。

私自身も異業界・異業種への転職を経験し、新しい環境で「どうしたらいいんだろう」と迷ったり、小さな不安を抱えたりした経験がありました。その経験から、同じような人が気持ちを少し軽くし、次の行動に移るきっかけを作ることを目指しています。

- ユーザーとの距離：過去の自分
- 利用場面：仕事や研修で疲れたとき、不安や戸惑いを感じたとき
- 利用方法：「癒しをもらう」ボタンを押してメッセージを受け取る
- 継続する理由：短時間で気軽に利用でき、気持ちを切り替えるきっかけになる

## アプリを作った理由
- 新年度が始まって1ヶ月が経ち、大なり小なり環境が変化した多くの方が疲れが出始めるころではないかと思います。そんな日々を頑張っている皆さんに、少しでも前向きになって、ほっとできるようなメッセージを伝えてくれるものを作りたいなと思い作成しました。
